# MiniCrawl 设计规范

> 2026-08-20 GMT+8  
> 美学方向：**声呐指挥室（Sonar Command Deck）** — 深碳底、磷光琥珀与信号青，等宽读数 + 人文黑体。拒绝紫渐变、拒绝 Inter。

## 1. 色彩

| Token | Hex | 用途 |
|---|---|---|
| `--bg` | `#07090C` | 页面底 |
| `--panel` | `#10161C` | 面板 |
| `--panel-2` | `#161E26` | 次级面板 |
| `--line` | `#24303A` | 分割线 |
| `--ink` | `#E7EEF4` | 主文字 |
| `--mute` | `#8B9AA8` | 次文字 |
| `--amber` | `#E8B84A` | 主强调 / 运行中 |
| `--cyan` | `#2EE6D6` | 检索 / 图谱节点 |
| `--danger` | `#FF6B4A` | 停止 / 错误 |
| `--ok` | `#7CFFB2` | 完成 |

网格底纹：`radial-gradient` 6px 点阵 + 极淡扫描线。禁止紫色。

## 2. 字体

- Display / 数字：`Oxanium`（600/700）
- 正文：`Noto Sans SC`（400/500）
- 等宽日志：`IBM Plex Mono`

## 3. 组件

- 按钮：直角微切角（`clip-path` 缺一角），hover 时边框磷光，禁止圆胶囊。
- 输入：深底 + 1px `--line`，focus 琥珀描边。
- Select：全局去掉原生箭头，右侧 12×8 折线 SVG（`#999`）。
- Toast：右上，可点 ×，5 秒关闭。
- Modal：自定义遮罩，禁止 `alert/confirm`。
- 日期展示：`yyyy-MM-dd HH:mm:ss`。

## 4. 布局

- 管理页：左侧航标轨 + 主区 `w-full`，**禁止**页面容器 `max-w-*`。
- 可视化页：顶栏 HUD + 全幅 Canvas 图谱；右侧可折叠情报条。
- 断点：768px 收起侧栏；480px 单列、表格横向滚动。

## 5. 动效

- 入场：面板 180ms 上移淡入，错开 40ms。
- 图谱：力导向 + 缓慢旋转扫描弧。
- 指标数字用 Oxanium，变化时轻微闪烁。
